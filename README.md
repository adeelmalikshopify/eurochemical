# Euro Water & Heat Proofing — Website

Single-page React (Vite) site for Euro Water & Heat Proofing, Lahore.

## Run locally

```bash
npm install
npm run dev
```

## Deploy (Vercel)

Import this repo in Vercel — it auto-detects Vite (build: `npm run build`, output: `dist`).

## Edit content

Phone, WhatsApp, rate, address, services, FAQ: `src/data.js`.
Images and videos: `public/media/`.
SEO (title, meta, schema): `index.html`, `public/sitemap.xml`, `public/robots.txt`.

Service photos are from Unsplash (Unsplash License — free for commercial use).
